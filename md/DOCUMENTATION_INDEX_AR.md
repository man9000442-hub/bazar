## دليل القراءة حسب الدور

### 👨‍💻 مطور Backend

**ترتيب القراءة:**

1. README_AR.md (البدء السريع)
2. PROJECT_SUMMARY_AR.md (البنية والموديلات)
3. MIGRATION_GUIDE_AR.md (الميزات الجديدة)

**نقاط مهمة:**

- استخدم `get_country_kwargs()` للفلترة
- استخدم `OrderService` للعمليات المعقدة
- اتبع قواعد الكود في README

---

### 🎨 مطور Frontend

**ترتيب القراءة:**

1. README_AR.md (البدء السريع)
2. PROJECT_SUMMARY_AR.md (الميزات)

**نقاط مهمة:**

- البيانات متوفرة عبر context processors
- لا تنسَ الفلترة حسب الدول
- استخدم template tags المتاحة

---

### 👨‍💼 مدير المشروع

**ترتيب القراءة:**

1. README_AR.md (نظرة عامة)
2. CHANGELOG_AR.md (التحديثات)
3. PROJECT_SUMMARY_AR.md (الحالة الحالية)

**نقاط مهمة:**

- التوافقية العكسية مضمونة 100%
- لا توجد متطلبات تحديث عاجلة
- كل الأنظمة تعمل بشكل طبيعي

---

### 🔧 مسؤول DevOps

**ترتيب القراءة:**

1. MIGRATION_GUIDE_AR.md (خطوات الترقية)
2. CHANGELOG_AR.md (التغييرات)

**نقاط مهمة:**

- شغّل `migrate` بعد التحديث
- راقب الأداء بعد الترقية
- احفظ backup قبل التحديث

---

### 🎓 موظف جديد

**ترتيب القراءة:**

1. README_AR.md (الفهم الأساسي)
2. PROJECT_SUMMARY_AR.md (التفاصيل)

**نقاط مهمة:**
