# سجل التغييرات (CHANGELOG)

جميع التحديثات الملحوظة لمشروع Bazarna سيتم توثيقها في هذا الملف.

---

## الإصدار 2.0.0 - أبريل 2026

### ✨ الميزات الجديدة

#### 1. نظام متعدد الدول 🌍

**الوصف:** دعم كامل لإدارة عدة دول بشكل منفصل مع معايير محلية لكل دولة.

**التطبيقات:**

- إضافة موديل `Country` جديد
- ربط جميع البيانات بالدول (Users, Products, Orders, etc.)
- إعدادات منفصلة لكل دولة
- فلترة ذكية للبيانات حسب الدول

**الملفات المتأثرة:**

```
accounts/models.py           # إضافة Country, CustomRole
store/models.py              # ربط النماذج بـ Country
supervisor/views.py          # دوال الفلترة الذكية
merchant_panel/views.py      # فلترة حسب البيانات
```

---

#### 2. أدوار وصلاحيات محسّنة 👤

**الوصف:** نظام أدوار متقدم مع 6 أدوار مختلفة وصلاحيات قابلة للتخصيص.

**الأدوار الجديدة:**

- `COUNTRY_ADMIN` - مدير الدولة (جديد)
- `CustomRole` - أدوار مخصصة (جديد)

**الملفات المتأثرة:**

```
accounts/models.py           # إضافة الأدوار والأدوار المخصصة
supervisor/views.py          # دوال التحقق من الصلاحيات
```

---

#### 3. إعدادات منفصلة لكل دولة ⚙️

**الوصف:** تحويل `SiteSetting` ليكون OneToOne مع Country بدلاً من أن تكون عامة.

**المميزات:**

- إعدادات مختلفة لكل دولة
- رسوم منفصلة
- بوابات دفع مختلفة
- المتغيرات البيئية محلية

**الملفات المتأثرة:**

```
store/models.py              # تحديث SiteSetting
supervisor/views.py          # استخدام get_settings()
merchant_panel/views.py      # الحصول على الإعدادات المحلية
```

---

#### 4. طبقة خدمات متقدمة 🎯

**الوصف:** فصل منطق العمليات المعقدة في طبقة خدمات مركزية.

**الخدمات:**

- `OrderService.calculate_merchant_shipping()` - حساب الشحن
- `OrderService.calculate_gateway_fees()` - حساب رسوم البوابة

**الملفات الجديدة:**

```
store/services.py            # طبقة الخدمات الجديدة
```

---

#### 5. نظام إشعارات محسّن 🔔

**الوصف:** تحسين نظام الإشعارات مع تتبع شامل.

**التحسينات:**

- `NotificationLog` - سجل تفصيلي للإشعارات
- دعم أجهزة متعددة (إزالة unique من FCM)
- تتبع رسائل الخطأ

**الملفات المتأثرة:**

```
accounts/models.py           # إضافة NotificationLog
store/utils.py               # تحسين دوال الإشعارات
```

### 🐛 الأخطاء المصححة

1. **مشكلة البيانات المتداخلة بين الدول**
   - ❌ المشكلة: البيانات تختلط بين الدول المختلفة
   - ✅ الحل: ربط كل البيانات بالدول مع فلترة ذكية

2. **عدم دعم بوابات دفع متعددة**
   - ❌ المشكلة: Paymob فقط
   - ✅ الحل: دعم Fawaterk مع اختيار البوابة حسب الدولة

3. **إعدادات موحدة لكل الموقع**
   - ❌ المشكلة: نفس الإعدادات لكل البلدان
   - ✅ الحل: إعدادات منفصلة لكل دولة
